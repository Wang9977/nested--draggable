# Nested Draggable

一个基于 Vue 3 + Vite 的嵌套可拖拽树形条件组组件。

## 功能特性

- **嵌套条件组**: 支持多层级的条件组嵌套
- **可拖拽排序**: 卡片和条件组都支持拖拽排序
- **层级限制**: 可配置最大层级数，超过限制时阻止拖拽并显示提示
- **逻辑组合**: 支持"且"和"或"两种逻辑组合方式
- **实时预览**: 左侧编辑区与右侧 JSON 预览实时同步

## 使用说明

### 添加卡片

点击"添加卡片"按钮添加新的卡片。

### 扩展卡片

点击卡片的"扩展"按钮，将卡片转换为条件组。扩展后的卡片成为条件组内的第一个子项。

### 拖拽操作

- **卡片拖拽**: 可以将卡片拖入条件组中
- **条件组拖拽**: 可以将条件组拖入其他条件组中
- **同组排序**: 在同一条件组内可以拖拽排序卡片和子条件组

### 层级限制

- 可通过右侧配置面板设置最大层级数（默认为 4）
- 当拖拽条件组会导致其内部卡片超过最大层级时，拖拽将被阻止
- 超过层级限制时，会显示 toast 提示

### 逻辑组合

当条件组内有多个卡片或子条件组时，点击中间的按钮可切换"且"和"或"逻辑。

### JSON 编辑器

- 右侧面板显示当前树形结构的 JSON 表示
- 可以手动编辑 JSON 后点击"应用"按钮应用到左侧树
- 点击"复制"按钮可复制 JSON 到剪贴板

## 数据结构

```json
{
  "level": 0,
  "operator": "且",
  "tags": [
    {
      "uid": 0,
      "name": "卡片 1",
      "valueDesc": "描述信息",
      "level": 1
    },
    {
      "level": 2,
      "operator": "且",
      "tags": [
        {
          "uid": 1,
          "name": "卡片 2",
          "valueDesc": "描述信息",
          "level": 2
        }
      ],
      "groupId": 1
    }
  ]
}
```

字段说明：
- `level`: 节点层级，根节点为 0
- `operator`: 逻辑运算符，"且" 或 "或"
- `tags`: 子节点数组，可以是卡片或条件组
- `uid`: 卡片唯一标识
- `groupId`: 条件组唯一标识
- `tags` (条件组): 包含子节点数组的条件组
